## Demonstrated website defects fixed in this run

1. **F-01 — content warnings hidden by the checkout gate.** Open a live Designer Frock 1 colour. Before the fix, the product and quick view only said checkout was limited to the ₹1 test item; the shared colour photo, generic name and missing measurements were concealed, and the Red image was labelled as though it showed only Red. The readiness checks now report content issues as well as the checkout restriction, and the card image uses a truthful collage description. **Retest:** automated readiness test passed; POS must still publish separate approved photos and facts.
2. **F-02 — stale browser title after leaving a product.** Open a product, then click Shop. Live navigation reached `/collections` while the browser title stayed `Product Details`. Removed the product effect's cleanup that overwrote the new route metadata. **Retest:** local product-to-Shop navigation shows `Shop | Rosepetal Designer Boutique`.
3. **F-03 — policy pages missing from search.** Search `privacy` on live: no policy result. Added Privacy, Delivery, Returns and Order information aliases. A post-deploy retest exposed a contradictory “No published pieces” message below the Privacy result, so the final fix hides that empty-product section when a page matches. **Retest:** final deployed `/search?q=privacy` shows the Privacy link without the conflicting message.
4. **F-04 — rapid enquiry clicks could enter the submit function twice before React updated `submitting`.** Added a synchronous in-flight guard while retaining the stable request ID for retries. **Retest:** lint/build and existing enquiry acknowledgement tests pass; live duplicate delivery needs an approved controlled submission and POS log review.
5. **F-05 — repeated gateway success callback could call payment verification twice.** Added a per-payment-ID reservation and an automated duplicate callback test. The Razorpay modal now reports closure without confirmation. **Retest:** synthetic callback test passes; real Razorpay/webhook replay remains unverified.
